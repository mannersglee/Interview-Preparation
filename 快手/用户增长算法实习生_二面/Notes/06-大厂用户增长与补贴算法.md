# 大厂用户增长与补贴出价：公开研究速览

> 截至 2026-11-02 的公开资料。这里的“已上线”只按论文作者披露，不能推断快手站内金币活动的内部架构。广告自动出价与金币补贴属于不同场景，迁移时要重新定义目标、成本和实验。

## 先看结论：与岗位最相关的技术链

随机实验与日志 → 多金额增量估计 → 预算约束决策 → 在线节奏控制 → A/B 长期验证。金币补贴的关键是 **谁因补贴新增活跃、给多少才值得**，不是谁最可能领取。生成式模型可以改进候选动作或序列策略，但预算、风控和因果评估仍需独立保证。

## 工业案例（按面试相关性排序）

| 企业与公开研究 | 实际算法 / 公开结果 | 对金币出价的启发与边界 |
| --- | --- | --- |
| **美团，2024/2026 修订**：[实时优惠券分配](https://arxiv.org/abs/2406.05987) | 对不同券额预测 CVR（Conversion Rate，转化率），以 isotonic regression 校准金额响应；拉格朗日对偶在线选券，反馈控制跟踪预算。作者报告单次决策 50 ms 内、覆盖超 1 亿用户，并通过现场实验验证。 | 最接近“多档补贴 + 大预算 + 实时分配”的系统范式。论文优化转化/收入，金币 DAU（Daily Active Users，日活跃用户数） 应改用增量活跃与长期体验，不能直接把 CVR 当 uplift。 |
| **美团，2022**：[多阶段骑手奖励分配](https://arxiv.org/abs/2202.10695) | 建接受概率模型、拉格朗日对偶动态规划和在线分配；作者报告线上取消订单减少超过 25%。 | 展示跨时段预算影子价格与动态分配；对象是骑手接单，不是用户活跃。 |
| **美团，MT-LIFT 数据集**：[官方仓库](https://github.com/MTDJDSP/MT-LIFT) | 多处理券实验数据来自随机对照试验，包含点击与转化链路标签。 | 可练多金额 uplift、链路指标和策略评估；实验数据尤其适合解释为何非随机投放会产生混杂。 |
| **阿里广告，2024**：[AIGB / DiffBid](https://arxiv.org/abs/2405.16141) | 条件扩散生成长时序自动竞价轨迹，以目标/约束为条件；作者报告阿里广告平台在线 A/B 的 GMV +2.81%、ROI（Return on Investment，投资回报率） +3.36%。 | “生成式出价”可理解为生成候选策略或轨迹；广告竞价目标和金币激励的因果效果不同，不能迁移收益数字。 |
| **快手广告，2024**：[GAS](https://arxiv.org/abs/2412.17018) | 生成式基础策略后，用小型 critic 和类似 MCTS 的搜索按偏好优化输出；论文报告快手广告在线实验的目标成本指标提升。 | 说明生成模型可与后训练搜索、约束筛选组合。该研究属于广告自动竞价，不能称为“快手金币补贴现有算法”。 |
| **快手广告，2025**：[CBD 扩散补全与对齐](https://arxiv.org/abs/2509.03348) | 对历史轨迹做条件补全，再用轨迹回报模型对齐竞价目标；论文报告快手广告线上目标成本指标提升 2.0%。 | 长期轨迹有效性和生成不确定性是重点；用于金币时还需金额上限、资格规则和因果评估。 |
| **淘宝直播，研究论文**：[动态券分配与批量深度强化学习](https://tuck.dartmouth.edu/uploads/content/RL（Reinforcement Learning，强化学习）_Livestream_Paper_04172022.pdf) | 将连续发券建成 MDP（Markov Decision Process，马尔可夫决策过程），用批量 Q-learning/DNN 估值，并用 DR（Doubly Robust，双重稳健） 离线评估后开展实验。 | 当金币改变未来习惯、补贴疲劳时，序列决策比单次 uplift 更合适；需特别防离线 RL 的分布外动作误差。 |

## 一套可在面试白板讲清的方案

1. **目标与动作**：状态 $x$ 只含决策时可见信息；动作 补贴动作 $a\in\{0,a_1,\ldots,a_K\}$。目标 $\max_\pi\mathbb{E}_{\pi}[v\,\Delta Y(X,A)-c(X,A)]$，约束每日/小时预算、单人频控、体验和风控。价值可先用增量活跃天数，长期留存独立监控。
2. **识别增量**：在合规小流量中用户级随机分配金额，记录分配概率、曝光、实际发放、核销和后续活跃。训练多处理 uplift / 剂量响应模型；评估各金额相对 0 元的 $\Delta Y(x,a)$，分主站与极速版检查校准。
3. **决策**：对每个请求计算 $s(x,a)=v\,\Delta Y(x,a)-\lambda\,\mathbb{E}[C(a)\mid X=x]$，枚举合规金额选最大；$\lambda $ 随预算消耗与预计流量调整。资格、单人限额、库存/预算由服务端硬校验。
4. **评估**：离线看随机实验上的策略价值、AUUC（Area Under the Uplift Curve，提升曲线下面积）/Qini、各金额覆盖和成本；用 IPS（Inverse Propensity Scoring，逆倾向得分加权）/DR 评估新策略时检查重叠性、propensity 和权重方差。线上 A/B 看去重增量 DAU、7/30 日留存、ROI/成本、投诉、刷量及预算节奏。
5. **迭代**：先用 GBDT（Gradient Boosting Decision Tree，梯度提升决策树）/共享多头与简单优化器建立基线；如长期路径重要，再试 contextual bandit / 保守离线 RL；如动作组合复杂，再试生成候选 + critic 重排。每一步都需在相同实验口径下证明价值。

## 面试官可能追问

| 问题 | 回答抓手 |
| --- | --- |
| 为什么预测券额 CVR 不够？ | CVR 是响应，不是相对不发券的增量；高 CVR 用户可能本来就活跃。 |
| 新策略给历史没出现过的金额，DR 能评估吗？ | 不能可靠评估；缺少支持集，需有界随机探索或先缩小候选金额。 |
| 影子价格为什么会变？ | 当预算消耗快于计划时提高 $\lambda $、提高出价门槛；慢于计划则相反，但要限制振荡。 |
| 为什么生成式出价不能直接上线？ | 生成分布可能偏向历史高补贴且未校准；要做候选约束、价值评估、预算校验、灰度 A/B。 |
| 主站与极速版如何共用模型？ | 共享表征但分产品校准或多任务头；看群体覆盖、增量异质性与线上分层效果。 |

## 阅读顺序（赶时间版）

1. 美团实时优惠券论文：理解 **预测 + 对偶优化 + 预算控制**。
2. MT-LIFT：理解 **随机化、多处理 uplift、点击到转化链路**。
3. AIGB 与 GAS：理解 **生成式出价的能力、搜索/约束和场景边界**。
4. 淘宝直播批量 RL：理解 **长期价值、离线评估和保守上线**。
