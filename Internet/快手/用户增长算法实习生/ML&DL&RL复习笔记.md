# ML、DL 与 RL 复习笔记：用户增长算法实习面试

> 复习主线：定义目标与标签 → 建模与优化 → 离线评估 → 因果验证 → 预算约束下上线。例子以金币补贴、活跃和留存为背景。

## 1. 先分清预测、因果与决策

- **预测**：估计用户在给定特征下的活跃概率 `P(Y=1|X)`。它可能把本来就会活跃的人排在前面。
- **因果**：估计发放补贴相对不发放的增量 `E[Y(1)-Y(0)|X]`（CATE/uplift）。同一用户的两个潜在结果不能同时观测，需要随机实验或额外识别假设。
- **决策**：对补贴档位 `a`，选择使增量价值减成本最大的动作，并满足总预算、频控、体验等约束。例如 `argmax_a {v·τ(x,a)-c(x,a)}`，其中 `τ(x,a)=E[Y(a)-Y(0)|X=x]`。
- **易错点**：高领取率、高预测活跃率不等于高增量；离线 AUC 高也不保证策略收益高。

## 2. 机器学习基础

### 2.1 数据、特征与切分

训练/验证/测试集各司其职：训练拟合参数，验证选择模型与超参，测试只做最终评估。增长业务优先按时间切分，并考虑用户级隔离，避免同一用户未来信息泄漏。曝光前可得的历史活跃、补贴历史、设备和场景可以作特征；曝光后领取、任务完成、当天活跃不能用于曝光时的在线预测。

缺失值要区分“真实缺失”和“未发生”，并保留缺失指示。类别特征可用 one-hot、目标编码或 embedding；目标编码必须在训练折内计算，避免标签泄漏。数值特征检查长尾、异常、分布漂移。训练与服务要使用相同的口径、时间窗口和默认值。

### 2.2 常见模型

| 模型 | 核心形式或机制 | 优势与常见追问 |
| --- | --- | --- |
| 线性/逻辑回归 | `p=σ(wᵀx+b)`；交叉熵拟合二分类 | 易解释、易校准；问正则化、共线性、类别不平衡 |
| 决策树 | 按特征阈值递归划分 | 可捕捉非线性与交互；深树易过拟合 |
| 随机森林 | 多棵 bootstrap 树做 bagging | 降方差、较稳健；推理成本和外推能力要注意 |
| GBDT / XGBoost / LightGBM | 逐轮拟合损失负梯度，加法模型 | 表格数据强基线；问梯度、叶子生长、正则、类别处理 |
| SVM | 最大间隔，软间隔加松弛变量 | 核技巧适合中小数据；大规模训练/概率输出不方便 |
| K-means | 最小化簇内平方距离 | 用户分群探索；需选 K、标准化，对异常点敏感 |

**偏差与方差**：欠拟合通常训练和验证都差；过拟合通常训练好、验证差。增大模型复杂度常降低偏差、提高方差；更多样本、正则化、早停和合理特征可改善泛化。训练/测试分布变化时，单靠降低训练误差无效。

**L1/L2 正则**：优化目标为经验损失加 `λ‖w‖₁` 或 `λ‖w‖₂²`。L1 可产生稀疏解；L2 平滑缩小权重。树模型通过深度、叶子样本数、叶子权重和学习率等控制复杂度。

### 2.3 损失函数与指标

- **二分类交叉熵**：`L=-[y log p+(1-y)log(1-p)]`；概率预测的标准损失。正负样本加权会改变最优概率，需要重新校准。
- **MSE / MAE**：分别重视大误差 / 对异常值更稳健。MSE 对应条件均值，MAE 对应条件中位数。
- **AUC**：随机正样本评分高于随机负样本的概率；衡量排序，不衡量概率校准。PR-AUC 对稀有正例更敏感，但受基准正例率影响。
- **LogLoss / Brier / 校准曲线**：检验概率质量。预算决策使用概率或增量数值时，校准尤其重要。
- **Precision、Recall、F1**：依赖阈值；先结合发券容量、误投成本与漏投成本选择阈值。类别极不平衡时准确率容易误导。
- **业务指标**：增量 DAU、7/30 日留存、每增量活跃成本、补贴消耗与体验护栏。离线分类指标不能替代随机 A/B 的策略效果。

### 2.4 类别不平衡与验证

先确认稀有事件是业务真实分布还是采样造成。可采用分层采样、类别权重或合理重采样；验证和测试必须保持目标人群分布。若训练时改变正例采样率，预测概率通常需要按真实先验修正或在真实分布验证集上校准。按用户或时间分组交叉验证，避免相同用户、同一实验周期在训练和验证间串漏。

## 3. 深度学习基础

### 3.1 前向、反向与优化

神经网络由仿射变换与非线性激活堆叠，如 `h=ReLU(Wx+b)`。反向传播用链式法则计算各层梯度。小批量 SGD 用当前 batch 的梯度更新参数；Adam 结合梯度一阶、二阶动量，通常易于初始调参，但仍需比较泛化并设置学习率策略。

**梯度问题**：深层网络中梯度连乘可能消失或爆炸。ReLU、合理初始化、残差连接、归一化和梯度裁剪分别缓解不同问题。BatchNorm 使用 batch 统计量，训练与推理行为不同；LayerNorm 在单样本特征维归一化，更适合变长序列或小 batch 场景。Dropout 训练时随机屏蔽激活，推理时关闭；它是正则化，不应替代充分的数据验证。

**训练排错顺序**：先检查标签和时间口径 → 用小样本过拟合确认模型可学习 → 查看训练/验证损失和梯度 → 调学习率、batch、正则 → 分人群分析。损失出现 NaN 时检查输入异常、学习率、对数的数值稳定性和混合精度溢出。

### 3.2 增长与推荐中的常见结构

- **Embedding**：将高基数用户、任务、场景 ID 映射为稠密向量，改善稀疏 one-hot 的参数共享；冷启动 ID 需要默认向量与内容侧特征。
- **MLP**：学习非线性组合；要与 GBDT 等表格基线比较，避免只因模型更复杂就采用。
- **Wide & Deep / DeepFM**：分别显式记忆低阶交叉、学习隐式高阶交互；适用于稀疏类别特征。面试要能解释 FM 的二阶交互如何用低秩向量内积表示。
- **双塔**：用户塔与候选塔分别编码，通过向量相似度召回；候选向量可预计算。双塔适合大规模候选检索，精排通常需更丰富的交叉特征。
- **多任务学习**：共享表示预测活跃、留存、领取、风险等；任务梯度冲突或标签稀疏时可用任务专属塔、门控结构，并检查负迁移。
- **序列模型 / Attention**：用行为序列建模兴趣和补贴疲劳。Attention 的 `softmax(QKᵀ/√d)V` 按相关性聚合信息；必须做时间因果遮罩和序列截断，避免读取决策后的行为。

### 3.3 训练与线上落地

负采样、曝光偏差和延迟反馈会使训练样本不代表线上决策人群。明确样本单位是用户、曝光还是用户×档位；标签观察窗必须完整。离线实验按时间和人群切分，报告整体及新老用户、主站/极速版等分层表现。上线关注特征新鲜度、延迟、吞吐、模型版本、兜底策略与漂移监控。

## 4. 本岗位必会的延伸：uplift 与出价

随机实验中，T-learner 分别拟合处理组和对照组的结果模型，再相减；S-learner 将处理指示作为特征；X-learner 先估计伪处理效应，适合处理组不平衡的某些场景。两模型相减会累积误差，需用独立实验样本评估。多档补贴可为每个档位估计相对零补贴的增量，并检查剂量反应、重叠性与高金额样本稀疏问题。

若增量收益 `v·τ(x,a)` 与成本 `c(x,a)` 可估，预算约束下可用拉格朗日乘子 `λ` 选择 `argmax_a {v·τ(x,a)-λc(x,a)}`，再通过调 `λ` 控制预算。实际还需小时级预算节奏、用户频控和异常流量拦截。历史策略日志用于离线评估时，必须记录每个动作的选择概率；IPS 权重 `π_new(a|x)/π_log(a|x)` 在小概率动作上方差很大，DR 结合结果模型与倾向得分，仍依赖重叠性和日志质量。

**A/B 核验**：按用户随机分流，预先定义增量 DAU、留存、成本及护栏；先查样本比例异常、埋点和实验污染，再看效应量与置信区间。短期代理指标可能与长期留存冲突，必须保留长期观察。更多检验方法见 [test_summary.md](test_summary.md)，岗位背景见 [understanding.md](understanding.md)。

## 5. 强化学习（RL）与在线出价

### 5.1 先判断是不是 RL 问题

**Contextual Bandit**：每次观察用户和场景 `x`，选一个补贴档位 `a`，收到该次决策的奖励 `r`；动作不显式改变未来状态。适合主要优化单次补贴的短期增量收益。**MDP**：动作会改变用户后续活跃、疲劳、预算剩余等状态，需优化多期回报。不能只因为决策是在线的就称为 RL；若历史数据固定、无需探索，监督学习加约束优化可能更简单。

MDP 五元组为 `(S,A,P,R,γ)`：状态、动作、状态转移、即时奖励、折扣因子。策略 `π(a|s)` 决定动作；回报 `G_t=Σ_{k=0}∞γ^k r_{t+k}`；价值函数 `V^π(s)=Eπ[G_t|s_t=s]`、`Q^π(s,a)=Eπ[G_t|s_t=s,a_t=a]`。Bellman 期望方程：`Q^π(s,a)=E[r+γE_{a'~π}Q^π(s',a')]`；最优方程将内层期望换成 `max_{a'}`。

**为什么 Bellman 方程成立？** 把总回报拆为“本步奖励 + 折扣后的下一步回报”：`G_t=r_t+γG_{t+1}`，再对当前状态和动作取条件期望即可。最优状态价值满足 `V*(s)=max_a E[r+γV*(s')|s,a]`；最优动作价值满足 `Q*(s,a)=E[r+γmax_{a'}Q*(s',a')|s,a]`。终止状态的后续价值为 0。`γ=0` 只看眼前，`γ` 越接近 1 越重视长期，但长周期估计也更难。

**马尔可夫性**：给定当前状态 `s_t` 后，下一状态和奖励不再依赖更早历史。用户行为往往不完全满足，因此要把近期活跃、最近补贴、疲劳程度等历史摘要纳入状态；若关键偏好无法观测，可将问题视为部分可观测 MDP（POMDP），用历史序列构造信念或表示。预算是全局资源，只把单个用户特征放进状态，会忽略当天剩余预算和未来流量。

增长场景中，状态可包含实验前用户行为、近期补贴次数、当前预算节奏；动作是不给补贴或给某一金额；奖励可由增量活跃价值减补贴成本构成。**增量奖励不能直接从单个用户的观测活跃与未观测反事实相减得到**，通常需随机实验、效果模型或群体层面的估计。若奖励包含 7 日留存，要处理反馈延迟与观察窗截断。用户体验和成本宜同时作为硬约束或护栏，避免只靠任意权重相加。

### 5.2 探索与利用：Bandit

| 方法 | 选动作方式 | 关键局限 |
| --- | --- | --- |
| ε-greedy | 以 `1-ε` 选当前最优，以 `ε` 随机探索 | 固定 ε 持续付探索成本；衰减过快会过早锁定 |
| UCB | 选“均值估计 + 不确定性奖励”最大的动作 | 经典保证依赖独立、平稳、有界奖励等条件 |
| Thompson Sampling | 从后验抽样参数，再按样本选最优动作 | 后验模型错设会影响探索；需监控随机概率 |
| Contextual Bandit | 利用用户和场景特征估计各动作收益 | 要处理特征漂移、选择偏差和动作覆盖 |

所有在线探索都应记录决策时的特征、候选动作、实际动作、策略版本及**选择该动作的概率**。补贴成本真实存在，探索应限定在安全档位、小流量和预算护栏内。非平稳环境可采用滑动窗口、折扣历史数据或重新训练；旧数据过多会拖慢适应。

**两臂数值例子**：补贴 0 元和 1 元的短期净收益估计分别为 0.4、0.6，但第二个估计来自很少样本。纯贪心会一直选 1 元；UCB 可能因 0 元的不确定性上界更高而暂时探索 0 元，待样本增加后再比较。若用 `ε=0.1` 的 ε-greedy 且随机探索均匀选两臂，当前最优臂的选择概率为 `0.9+0.1/2=0.95`，另一臂为 `0.05`；这两个概率就是离线评估所需的 propensity。若某臂被完全禁止，其选择概率为 0，不能用该日志无偏评估会选它的新策略。

**Regret（后悔值）**：`R_T=Σ_{t=1}^T(μ*(x_t)-μ_{a_t}(x_t))`，衡量探索策略相对每轮最优动作损失多少期望奖励。理论上较低的 regret 不必然意味着业务上可接受，因为预算超支、用户投诉等约束可能未包含在奖励里。

### 5.3 经典 RL 算法

- **Monte Carlo 与 TD**：MC 等轨迹结束后用完整回报更新，估计偏差较小但方差和等待时间较大；TD 用 `r+γV(s')` 自举，可逐步更新但引入估计偏差。TD 误差为 `δ=r+γV(s')-V(s)`。
- **Q-learning**：离策略更新 `Q(s,a)←Q(s,a)+α[r+γmax_{a'}Q(s',a')-Q(s,a)]`，目标为最优 Q；SARSA 是在策略更新，使用实际按当前策略选出的 `a'`，因而会考虑探索行为带来的风险。
- **DQN**：用神经网络近似 Q，经验回放降低样本相关性，目标网络缓解目标不断移动。仍可能高估 Q 值；Double DQN 将动作选择与目标评估分开。离散补贴档位适用，大动作空间或严格约束下需要额外设计。
- **策略梯度**：直接优化 `J(θ)=E_{πθ}[G]`，REINFORCE 的梯度估计为 `E[∇θ log πθ(a|s) G]`；减去与动作无关的 baseline 不改变期望梯度，可降低方差。
- **Actor-Critic / PPO**：Actor 更新策略，Critic 估计价值或优势 `A(s,a)=Q(s,a)-V(s)`；PPO 用裁剪的概率比限制单次策略更新幅度。它提高训练稳定性，但不自动保证业务预算与安全约束。

**离策略与在策略**：离策略算法可学习与采样策略不同的目标策略，适合复用日志，但需要覆盖和偏差控制；在策略方法主要依赖当前策略采样，在线样本成本更高。两者都不能跳过离线评估和小流量 A/B。

**一步 TD 手算**：设当前 `Q(s,a)=2`、即时奖励 `r=1`、下一状态最大 Q 为 `4`、`γ=0.9`、`α=0.1`，则 TD 目标为 `1+0.9×4=4.6`，误差为 `4.6-2=2.6`，更新后 `Q(s,a)=2+0.1×2.6=2.26`。若下一状态已终止，目标只有 `r=1`。

**DQN 为什么需要两种稳定机制？** 连续的用户行为样本高度相关，经验回放打乱相关性并重复利用样本；若网络同时生成目标和被更新值，目标会跟着参数不断变化，目标网络定期或平滑更新以减弱该问题。Double DQN 的目标可写为 `r+γQ_target(s', argmax_a Q_online(s',a))`，把“选最大动作”和“评价动作”分给两个网络，缓解最大化带来的高估。

**策略梯度细节**：由 `∇θπθ(a|s)=πθ(a|s)∇θlogπθ(a|s)`，可把期望奖励的梯度写成采样可估的形式。实际常用优势函数替代完整回报：`∇J≈E[∇logπθ(a|s) A(s,a)]`；正优势提高该动作概率，负优势降低。PPO 用 `ρ_t=πθ(a_t|s_t)/π_old(a_t|s_t)`，优化 `min(ρ_t A_t, clip(ρ_t,1-ε,1+ε)A_t)` 的期望，以抑制单次更新过大。裁剪是训练上的限制，不等于预算或体验的硬约束。

| 算法 | 学习对象 | 数据利用 | 更适合的情形 |
| --- | --- | --- | --- |
| Tabular Q-learning / SARSA | 状态动作价值表 | 可复用历史转移，但覆盖不足会偏 | 小状态、小离散动作，理解算法原理 |
| DQN | 神经网络近似 Q | 经验回放，离策略 | 状态复杂、动作档位有限 |
| Policy Gradient / PPO | 参数化策略 | PPO 通常依赖当前策略数据 | 策略分布需要直接建模，允许在线采样 |
| Contextual Bandit | 单步各动作期望收益 | 可利用随机日志 | 即时或固定窗口结果为主、状态转移不重要 |

### 5.4 离线 RL 与策略评估

历史补贴日志由旧策略产生，新策略若选择历史几乎从未尝试的金额，无法可靠估计效果，这叫**支持集/重叠性问题**。单步 Bandit 可用 IPS、SNIPS、DR；长轨迹的重要性采样权重是各步概率比的乘积，方差可能随轨迹长度快速增长。模型化评估又受状态转移模型错设影响。实践中应限制新策略偏离日志策略的程度，报告有效样本量、分层结果和置信区间，再以随机实验验证。

设日志有 `n` 条 `(x_i,a_i,r_i,p_i)`，其中 `p_i=π_log(a_i|x_i)>0`。目标策略为 `π`，单步策略价值的 IPS 估计为 `V̂_IPS=(1/n)Σ_i [π(a_i|x_i)/p_i]r_i`；确定性目标策略只给其选中动作权重。SNIPS 为 `Σ_i w_i r_i/Σ_i w_i`，常降低方差但有限样本有偏。DR 先用结果模型 `q̂(x,a)` 估计所有动作价值，再用加权残差纠偏：`V̂_DR=(1/n)Σ_i{Σ_aπ(a|x_i)q̂(x_i,a)+w_i[r_i-q̂(x_i,a_i)]}`。在常见条件下，倾向概率或结果模型有一方正确时，DR 可一致；方差和支持集问题仍需检查。

**OPE 诊断清单**：检查 propensity 是否真是决策当时的概率、是否有 0 或极小值；报告权重分布、最大权重和有效样本量 `ESS=(Σw_i)²/Σw_i²`；按人群和档位看覆盖；做时间切分与置信区间。裁剪大权重能降方差但引入偏差，须披露阈值并做敏感性分析。长轨迹下逐步概率比相乘容易爆炸或趋零，可考虑 per-decision IS、模型化估计或更保守的策略改进。任何 OPE 都不能替代真实 A/B。

预算约束使单个用户的最优动作依赖剩余预算和未来流量。可在状态中加入剩余预算和时间，也可使用预算影子价格/拉格朗日乘子做实时出价；前者状态空间更大，后者需持续校准预算节奏。对亿级补贴，稳定性、可解释的兜底与异常回滚通常和平均奖励一样重要。

### 5.5 补贴出价的完整建模例子

假设每次访问时可选 `a∈{0,1,2}` 元，目标是在日预算 `B` 内增加 7 日活跃天数。决策前状态 `s_t` 包含用户近 7 日活跃、历史补贴次数、距上次补贴时间、产品端、当天剩余预算与剩余时段。动作后记录实际花费、当天行为和后续 7 日活跃；为避免未来信息泄漏，训练样本要等观察窗完整后才用于对应标签。对用户频控、单人上限和异常账号设置动作掩码；预算耗尽时强制 `a=0`。

一个可解释的奖励是 `r_t=v·(活跃增量估计)-实际补贴成本`。若用观测到的活跃天数直接作奖励，策略可能偏爱原本高活跃的用户；若直接减去每用户的“无补贴活跃”，该反事实又不可观测。可先通过随机试验估计不同档位的增量，再做 contextual bandit 或预算优化。只有当“今天补贴改变之后多天的用户状态”带来的长期收益足够重要、且有可靠连续轨迹时，再升级为 MDP/RL。升级后可定义 `r_t=当天收益-当天成本`，把后续留存体现在未来奖励，避免同一留存收益在多步重复计数。

**从离线到上线**：① 随机小流量采集安全档位及其选择概率；② 用监督模型估计各档位收益和不确定性，建立不发补贴/固定规则基线；③ 用 IPS/DR、预算回放和时间切分筛掉明显差的候选；④ 小流量 A/B 比较增量 DAU、7 日留存、每增量活跃成本及体验护栏；⑤ 扩量时实时调整预算影子价格并保留回退规则。观察到总体活跃上升但成本增长更快时，策略仍可能不值得上线。

### 5.6 RL 高频追问

1. **Bandit 与完整 RL 的区别？** Bandit 主要处理当前动作的即时反馈；RL 还处理动作改变未来状态与延迟回报。应由业务反馈机制决定建模形式。
2. **为什么需要探索？** 只按当前估计选动作会缺乏其他档位的数据，无法确认其真实价值；探索换取信息，但要控制真实补贴成本。
3. **为何不能直接在历史日志上训练最优策略？** 日志有旧策略选择偏差，未尝试动作没有可靠标签；还可能有未记录的动作概率和时间漂移。
4. **Q-learning 与 SARSA 有何区别？** Q-learning 用下一状态的最大 Q 值更新，偏向学习最优目标策略；SARSA 用实际下一动作更新，反映当前探索策略。
5. **RL 奖励怎么设计？** 结合增量 DAU/留存价值和补贴成本，明确反馈窗口；对预算超支、投诉、刷量设置约束与护栏，并检查奖励被策略钻空子的可能。
6. **如何上线？** 先用随机实验建立覆盖，离线评估新策略及不确定性，小流量灰度，监控预算节奏、增量效果和护栏，再逐步扩大。
7. **为什么 `γ` 不能随便设为 1？** 无限期任务可能使回报不收敛；较大 `γ` 也会放大长期估计误差。有限观察窗可用明确终止状态，并结合业务时间尺度选择折扣。
8. **什么时候用 DQN，什么时候用 PPO？** 离散少量档位且希望复用历史转移，可考虑 DQN；需要直接建模随机策略且能获得当前策略样本，可考虑 PPO。两者都要与 Bandit 和规则基线比较。
9. **为什么普通监督学习会有反馈回路？** 只给某些用户发券后，训练数据主要包含这些用户在该动作下的结果；模型的后续选择会进一步改变样本分布，需要探索概率、随机对照和漂移监控。

## 6. 高频面试问答速记

1. **AUC 高为什么业务效果可能差？** AUC 衡量自然标签排序；补贴策略需要增量效果、成本和预算下的策略价值。模型也可能未校准或发生线上漂移。
2. **为什么不能把领取金币当作主要标签？** 领取是补贴后的中间行为，优化它可能提高成本，却不增加 DAU 或留存；还可能造成选择偏差。
3. **GBDT 与深度模型如何选？** 先用相同时间切分和特征口径做表格基线；高基数稀疏特征、序列和多任务可能使深度模型受益，同时比较推理延迟与维护成本。
4. **如何发现数据泄漏？** 核对每个特征的产生时间与线上可用时间；做时间切分，检查异常强特征、训练验证差距和特征上线可复现性。
5. **过拟合如何处理？** 先确认切分无误，再看训练/验证曲线；减少复杂度、加正则和早停，增加有效数据，并按人群检查漂移。
6. **多档补贴为什么不能只训练一个活跃预测模型？** 不同金额对应不同潜在结果；需要比较相对无补贴的增量和边际成本，且历史金额分配可能有选择偏差。
7. **离线策略评估需要什么？** 目标策略、历史动作概率、结果及足够的动作重叠；报告 IPS/DR 估计与方差，并通过小流量随机实验验证。
8. **模型上线后看什么？** 增量 DAU、留存、每增量活跃成本、预算消耗节奏、投诉/疲劳/刷量护栏、延迟和特征漂移。
