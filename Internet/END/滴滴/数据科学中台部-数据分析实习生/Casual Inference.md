# 因果推断快速入门：面向数据科学评估岗位

> 文件名沿用题目中的 `Casual Inference.md`；学科英文名称是 **Causal Inference**。本文依据 `岗位介绍.md` 和 `note.md` 整理。补贴、订单、司机等均为假设场景，不代表目标团队的实际业务。

## 先抓住一个问题

岗位的核心是提高策略评估的**可信度**：策略是否真的造成指标变化？变化有多大？这个证据足以支持推广吗？

假设某城市发放乘客补贴后，日订单从 10 万涨到 11 万。不能直接说“补贴带来 1 万单”，因为天气、节假日、竞争活动和司机供给也可能变化。真正想知道的是：**同一城市、同一时段，如果没有补贴，会有多少订单？**这个看不到的结果叫反事实。

用潜在结果写作 $Y_i(1)$（接受策略）和 $Y_i(0)$（未接受策略）。同一个对象在同一时点只能观察其中一个，所以因果推断要设计一个可信的替代比较。总体平均处理效应是 $ATE=E[Y(1)-Y(0)]$；已接受处理者的平均效应是 $ATT=E[Y(1)-Y(0)\mid D=1]$。先说清目标人群，才知道估计的是哪个效应。

## 一张方法选择图

```text
能随机分配策略？
├─ 能 → A/B 实验：优先使用，按实际分配估计 ITT
│   └─ 有跨组影响？→ 考虑区域/城市集群或时段切换设计
└─ 不能 → 找到可辩护的自然比较
    ├─ 有处理组、对照组和干预前后数据 → DiD
    ├─ 资格由明确阈值决定 → RDD
    └─ 选择机制主要由已测量的干预前特征解释 → 匹配/加权
```

方法名称不是可信度保证。每种设计都要说明**对照为何能代表反事实**，并检查其关键假设。

## 第一站：把 A/B 实验真正做对

1. **定义问题**：谁入组？随机化单元是用户、司机、城市还是时段？主指标的分母、观察窗口和最小业务价值是什么？同时预设成本、等待时长、取消率、司机收益等护栏。
2. **分流和执行**：固定分组键与比例，记录随机分配 $Z$、实际曝光/接受 $D$、退出和缺失。优先按原分配比较，得到意向性治疗效应 $ITT=E[Y\mid Z=1]-E[Y\mid Z=0]$。只比较实际曝光者可能产生选择偏差。
3. **先查质量**：在本应被随机分配的入组总体检查组别比例异常（SRM）；沿入组、分流、曝光、日志、指标计算追踪样本。曝光子集的组别比例未必等于预设比例。
4. **按设计推断**：若按城市分流，就不能把每笔订单当作独立随机样本；同一用户的多笔订单也有关联。报告效应大小、置信区间、样本量和业务阈值，而不只报 $p$ 值。
5. **处理干扰**：补贴可能吸引共享司机，改变对照组等待时间。用户级实验此时可能无法代表全量推广效果；要界定干扰范围，必要时改用集群或时段设计。

**一分钟例子**：预先定义“每名入组乘客 7 天内完成订单数”为主指标。随机分配补贴后，先核对入组比例和日志，再按乘客汇总比较两组均值；若司机在两组间共享且供给紧张，明确报告潜在溢出，并考虑区域级试验验证全量效果。最后将订单增量换算成净收益，同时看取消率和司机收益。

## 第二站：不能随机化时，识别假设要说出口

| 方法 | 适用例子 | 核心假设 | 关键检查 |
| --- | --- | --- | --- |
| 双重差分（DiD） | 一些城市先上线策略，另一些尚未上线 | 若不上线，两组会有可比的变化趋势 | 画干预前趋势，排查城市独有同期事件、提前反应和溢出；预趋势检验不显著不等于证明平行趋势 |
| 断点回归（RDD） | 评分超过阈值才获得资格 | 阈值附近潜在结果连续，不能精准操纵评分 | 查评分分布、干预前特征是否在阈值跳变，比较不同带宽；结论主要适用于阈值附近 |
| 匹配/加权 | 根据历史活跃度等选择触达用户 | 所有重要共同原因已测量，处理与对照有重叠 | 只用干预前变量；查重叠、加权后平衡和极端权重；无法消除未观测混杂 |

两期 DiD 的直觉是：**处理组前后变化 − 对照组前后变化**。若处理城市同时发生大型活动，活动的额外影响会被误认为策略效果。复杂回归不能替代对这个机制的判断。

## 看结果时最容易犯的五个错

- **前后上涨就归因于策略**：缺少可信反事实。
- **`p < 0.05` 就推广**：还要看效应区间、补贴成本、护栏和推广范围。
- **不显著就判定无效**：小样本可能无法排除有业务价值的正效应；看置信区间和预设的最小价值。
- **筛很多人群后挑显著项**：先确定主分析；探索性异质性结果要独立验证。
- **控制所有能找到的变量**：干预后的变量可能是中介或碰撞变量，反而引入偏差。

## 岗位上可复用的评估流程

`业务决策 → 干预与目标总体 → 指标和阈值 → 实验/准实验设计 → 数据质量诊断 → 效果及不确定性 → 护栏、成本、异质性 → 推广建议与局限`

中台岗位还需要把这条链路标准化：版本化指标字典、实验登记、自动 SRM/缺失检查、可复现代码和报告模板。AI agent 可辅助查口径、生成查询和初稿，但分流机制、识别假设及结论仍需人工核验。

## 30 分钟自测

1. 为什么“补贴后订单增长 10%”不是因果结论？说出至少三个替代解释。
2. 用户级随机分流后，同一司机服务两组乘客，会影响什么假设？怎样调整设计？
3. 随机分配、实际曝光、实际使用分别是什么？为什么通常先报 ITT？
4. 城市级试验有 20 个城市、千万笔订单，决定推断精度的关键样本单位是什么？
5. DiD 的平行趋势具体在说什么？哪些业务事件可能破坏它？
6. 主指标点估计为正但区间跨过零，你会如何向业务方解释下一步？

**参考答案**：

1. **缺少反事实**。“增长 10%”只是上线后的前后变化。同期天气变好、节假日出行增加、竞争对手减少补贴，或司机供给增加，都可能推高订单。应比较同一时期的可信对照组；能随机分配时优先做 A/B 实验。
2. **可能违反无干扰假设**。补贴组乘客吸引同一批司机，会改变对照组的等待时间、成交率和订单量。先判断干扰范围：若主要在区域内发生，可按区域或城市集群随机；若策略可快速切换且残留效应小，可考虑时段切换。还要检查跨区域流动，并按实际随机化单元推断。
3. **分配、曝光、使用是三层不同事件**。分配是随机决定某人进入哪组；曝光是实际看到或收到策略；使用是实际领取、消费等行为。ITT 按原始分配比较所有入组对象，保留随机化带来的可比性，回答“推行这套分配策略有什么效果”。只比较使用者和未使用者会混入活跃度、需求等自选择差异。
4. **关键是 20 个被随机分配的城市**，而非千万笔订单。城市内订单共享供需、天气和策略，彼此相关；把订单当成独立样本会使标准误过小。应按城市层面分析或使用与城市分流相符的推断方法，并注意城市数少时常规大样本近似可能不稳。
5. **平行趋势说的是无策略时的变化**：若处理城市未上线策略，其指标本会与对照城市呈可比趋势，不要求两组水平相同。只有处理城市发生大型活动、天气异常、竞争变化、司机供给冲击，或提前预期策略、样本组成变化，都可能破坏该假设。干预前趋势相近只是支持性证据，不能证明干预后的反事实趋势。
6. **报告“有正向迹象，但证据仍不确定”**，同时给出效应点估计、置信区间和预设最小业务价值。若区间上界仍高于最小有价值效应，不能排除值得推广的收益；若上界低于它，则当前数据已不支持有业务价值的收益。先确认分流、指标、干扰和护栏，再依据预定方案决定增加样本、改进测量或调整策略；不能因区间跨零就直接说“无效”，也不能仅凭点估计为正就推广。

**面试回答模板**：先说要支持的业务决策；解释为什么简单相关性不够；说明目标人群、干预、对照和指标；交代随机化或识别假设；展示数据质量检查；报告效果区间、成本和护栏；最后给出有条件的建议与局限。若举 `demos/` 中的例子，明确它是模拟案例。
