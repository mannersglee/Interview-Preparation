# 互联网 A/B（A/B Test，A/B 对照实验）设计与分析手册

## 本文其他缩写

UGC（User-Generated Content，用户生成内容）；ITT（Intention-to-Treat，按原始分组估计的意向治疗效应）；MDE（Minimum Detectable Effect，最小可检测效应）；SE（Standard Error，标准误）；SRM（Sample Ratio Mismatch，样本比例不匹配）；AA（A/A Test，同策略双组检验）；CUPED（Controlled-experiment Using Pre-Experiment Data，利用实验前数据降低方差的方法）；CTR（Click-Through Rate，点击率）；ROI（Return on Investment，投资回报率）。下文沿用缩写。

## 1. 实验回答什么

目标是估计一个**明确策略**对**明确人群、时间窗、指标**的增量影响。随机化让处理与对照在期望上可比，但不自动修复埋点错误、用户干扰、选择性曝光或事后挑选指标。

## 2. 设计阶段

1. **决策问题**：例如“新 UGC 创作者激励是否应全量上线”，而不是“是否能找到显著指标”。
2. **估计对象**：分配策略的 ITT、实际触达者的效果，或特定人群的效果；不要混写。
3. **分流单元**：用户、设备、作者、主播、商家、地区或时间块。分流单元与分析单元不同，标准误需按随机化/依赖结构处理。
4. **指标**：预先定一个或少数主指标，列护栏；写分子、分母、时间窗、延迟回填和样本过滤。
5. **样本量/周期**：基线方差、MDE、显著性水平 α 和功效决定样本量；覆盖周内周期和结果反馈时滞。
6. **执行规则**：固定随机种子/哈希、互斥层、灰度比例、停止/回滚阈值、监控负责人。

## 3. 分析阶段

### 最小理论推导

对用户级随机实验，最朴素的平均处理效应估计为 `Δ̂ = mean(Y_T) - mean(Y_C)`；若两组用户相互独立，近似标准误为 `SE(Δ̂) = sqrt(s_T²/n_T + s_C²/n_C)`。置信区间可写作 `Δ̂ ± z_(1-α/2)×SE`。若随机化单位是用户、结果却按订单/曝光记录，先聚合到用户，或使用与随机化层级一致的聚类方法；直接把订单当独立样本会低估不确定性。

样本量的直觉是：**MDE 越小、方差越大，所需样本越多**；平衡分流通常更有效率。先确定实验希望发现的最小业务价值，再算样本量，避免事后用实际观察到的效果反推功效。

**验数顺序：**实验注册信息 → 分流人数与 SRM → 实验组/对照组曝光及日志完整性 → 基线变量 → 指标计算 → 效果估计 → 护栏和异质性 → 决策。

- **SRM（样本比例不匹配）**：实际组别比例显著偏离预设，先排分流、过滤、日志、身份合并和端版本；原因未明时暂停效果解读。
- **AA 实验**：两组配置相同策略，用来检查分流、指标方差和数据链路。一次 AA 正常不代表永久正常。
- **效应与区间**：报告处理组与对照组均值、绝对差、相对差、置信区间、样本量和业务最小有价值效果。`p < 0.05` 不是上线规则。
- **CUPED**：用干预前协变量 `X` 构造 `Y_adj = Y - θ(X - E[X])`，通常 `θ = Cov(Y,X)/Var(X)`；检查缺失、方差下降和是否用了干预后信息。
- **比率指标**：用户均点击数、CTR、ROI 等要注意分子分母相关性和分析粒度；不能把同一用户的多条曝光当作独立样本。
- **多重检验和窥探**：大量指标/分群反复查看会抬高假阳性。预注册主分析；探索结果另标注并复验。

## 4. 特殊场景

| 场景 | 风险 | 应对思路 |
| --- | --- | --- |
| 社交/内容/直播 | 用户与作者互相影响，处理可能溢出到对照 | 按社区、作者或地区聚类分流，估计总体生态影响 |
| 搜索/广告 | query、广告预算、竞价系统存在干扰 | 检查共享预算与拍卖交互；必要时改分流层级或设计 |
| 长期留存 | 实验短于结果反馈周期 | 设可靠代理指标，但保留长期追踪和后验验证 |
| 小流量/稀有事件 | 统计功效低 | 延长周期、方差缩减、合适聚合；不把不显著说成无效 |
| 新策略分阶段发布 | 灰度和实验混淆 | 记录版本、曝光和分流快照，明确比较对象 |

## 5. 公开工业实践

美团《可信实验白皮书》公开讨论了分流单元与分析单元不一致时的方差计算陷阱、比率指标与实验平台方法库；这说明线上实验平台必须把统计正确性固化为流程。[美团可信实验白皮书](https://tech.meituan.com/2025/05/22/meituan-AB-Online-Controlled-Experiment-01.html)、[开放式分析引擎](https://tech.meituan.com/2025/08/22/meituan-AB-Online-Controlled-Experiment-08.html)

Netflix 公开介绍用 interleaving 快速筛选候选排序算法，再用常规 A/B 测长期行为；这是“快速筛选与最终决策指标分层”的案例，不能用 interleaving 结果直接替代长期 A/B。[Netflix 技术博客](https://netflixtechblog.com/interleaving-in-online-experiments-at-netflix-a04ee392ec55)
