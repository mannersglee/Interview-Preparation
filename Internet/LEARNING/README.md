## 阅读方法

每篇先读“问题与目标”，再读“理论”，最后看“公开实践”和“自己如何落地”。公开实践仅指企业或论文公开披露的方法，不推断未公开的团队架构。论文中的离线效果与企业线上结果也不能混为一谈。面试准备可配合 [八股文](../八股文/README.md) 和 [PRE 岗位专项](../PRE/03-岗位专项与面试题.md)。
