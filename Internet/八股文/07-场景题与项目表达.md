# 场景题与项目表达

## 业务场景的 5 分钟回答法

**第 1 分钟：定义问题。** 问清时间、城市、用户群、指标口径、变化幅度和业务目标。不要未验数就提出“改模型”。

**第 2 分钟：拆指标。** 按总量 = 流量 × 转化 × 频次/价值拆解，再按新老用户、渠道、版本、设备、地区、内容/商品类别找贡献最大处。

**第 3 分钟：列可证伪假设。** 数据问题、产品变更、供给变化、活动、推荐策略、竞品等，每个假设配一个查询或实验。

**第 4 分钟：选择验证方法。** 有随机实验看分流和效果；无随机实验谨慎用同期对照、DiD、匹配等，说明假设。

**第 5 分钟：给决策。** 建议先做什么、观察什么护栏、何时复盘，以及证据不足时需要什么额外数据。

## 高频案例

**1. 某产品 DAU 下降 8%。** 先验日志和时区；拆新增与存量、渠道与版本；若集中在安卓新版本，查崩溃、加载、登录和埋点；若全渠道同步下降，考虑节假日、活动结束和供给变化。结论需给贡献量，不只列猜测。

**2. 抖音 UGC 投稿上升，用户互动率下降。** 投稿作者结构可能变化，新内容质量或曝光分配变化；互动率分母需明确为曝光、观看还是用户。看有效投稿率、审核通过率、作者留存和低质内容护栏。

**3. 搜索 CTR 提升，订单下降。** 先查 query 与商品结构、点击位置偏差、CVR、客单价、退款；可能更吸睛却不相关。需看搜索成功率和长期满意度。

**4. 直播观看时长增长，主播流失。** 观看集中到头部、长尾主播曝光减少；按主播分层看开播频次、收益、互动和留存。平台的双边供需不能只优化观看端。

**5. Agent 调用量上升，满意度下降。** 新入口可能带来低意图用户，失败重试也会推高调用量。按任务而非消息去重，看成功率、人工接管、时延与 bad case；质检成功判定。

**6. 标签覆盖率提高，营销效果变差。** 新增覆盖人群可能低质量，标签时效或口径变化；看覆盖、精确率、不同人群误判成本与策略实验效果。不能只用离线准确率决定标签价值。

## 简历项目的真实表达

**量化研究实习，1 分钟版：**“我在量化研究实习中负责高频行情数据清洗、数据库读写和跨机器一致性检查，并设计统计检验评分体系来比较策略样本内外表现。关键收获是先保证数据和验证过程可信，再解释策略效果。”如被问性能提升或规模，没有可靠数字就不编造。

**动态因果效应研究，1 分钟版：**“我研究睡眠纵向数据中呼吸暂停对心率变异性的时变影响，使用潜在结果框架和非参数局部线性回归，论文盲审和答辩获 A。迁移到互联网策略时，我会先明确干预、结果、时间窗和识别假设；线上 A/B 的分流与埋点还需要另行设计。”

**在线医疗项目，1 分钟版：**“我负责 Python 数据获取、清洗、回归拟合，结合结构化信息与文本、照片特征，比较逐步回归、岭回归和 Lasso，识别与医生就诊量相关的因素并形成建议。这里主要是相关性分析，不直接声称因果效应。”

## 反问面试官

1. 这个岗位近期最常处理的业务决策是什么？
2. 团队的主指标和护栏指标分别是什么，指标口径由谁维护？
3. 实习生会参与哪些环节：取数、实验设计、分析报告、上线复盘或模型实现？
4. 目前最影响分析可信度的数据质量问题是什么？
5. 对实习生前 1–2 个月的交付预期是什么？

## 临场自检

答题时不确定就说假设，别把未经验证的推测说成结论；先给主线再展开细节。涉及模拟项目，要主动说明数据来源和边界。结束前给出“下一步会查什么或验证什么”。
