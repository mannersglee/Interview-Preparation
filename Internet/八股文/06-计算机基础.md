# 计算机基础高频题

这部分对数据分析岗通常次于 SQL、实验和业务题；推荐算法岗需要更熟悉。回答时先说明适用场景，不把所有系统细节背成固定结论。

## Python

**Q：列表、元组、集合、字典？** 列表可变有序；元组不可变有序；集合去重且无业务排序保证；字典按键映射。选择结构前看是否需要顺序、唯一性、按键查找和可变性。

**Q：浅拷贝和深拷贝？** 浅拷贝复制外层容器，嵌套对象仍共享；深拷贝递归复制可复制对象。处理嵌套配置或特征字典时要避免意外共享。

**Q：生成器有什么用？** 惰性产生数据，适合流式处理和减少峰值内存；不是任何情况下都更快。大规模日志处理仍要考虑批量化、I/O 和重复遍历。

**Q：可变默认参数问题？** 默认参数在函数定义时创建，重复调用会共享同一个对象。常用 `None` 作默认值，在函数内新建列表/字典。

**Q：Pandas 中 `apply` 一定比循环快吗？** 不一定。优先向量化和合理的数据类型；`apply` 可能仍逐行执行。先测量瓶颈并检查内存。

## 数据结构与算法

**Q：哈希表平均与最坏查找复杂度？** 平均常接近 O(1)，碰撞严重时可能退化；实际表现还受装载因子、扩容和键哈希影响。

**Q：堆用于什么？** 维护 Top-K、优先队列；扫描 N 项保留 K 个最大值通常可用大小为 K 的最小堆，复杂度 O(N log K)。

**Q：二分查找前提？** 搜索空间有单调性；要明确左右边界和停止条件。预测阈值、时间窗口查找可能用到。

**Q：排序稳定性？** 相同键元素的原相对顺序保持不变称稳定。多字段排序、按时间再按分数处理数据时要明确需求。

## 数据库与系统

**Q：索引为什么可能让查询快？** 减少需要扫描的数据；但索引占空间、增加写入维护成本。是否命中取决于查询谓词、选择性和执行计划。

**Q：事务 ACID？** 原子性、一致性、隔离性、持久性。隔离级别影响脏读、不可重复读、幻读等现象；具体保证要看数据库实现。

**Q：OLTP 与 OLAP？** OLTP 偏高并发短事务读写；OLAP 偏大量数据扫描、聚合和分析。大表日常指标查询通常走分析型系统而非逐条交易库。

**Q：批处理与流处理？** 批处理适合延迟容忍的离线计算；流处理适合实时监控和反馈。需权衡时效、成本、迟到事件、去重及结果修正。

**Q：幂等性？** 同一操作重复执行与执行一次有相同结果。数据回填、重试和消息消费应设计幂等键，避免重复计数或重复写入。

## 网络与服务

**Q：HTTP 与 HTTPS？** HTTPS 在 HTTP 外加 TLS，提供传输加密、完整性和服务端身份验证；不代表业务数据本身必然正确。

**Q：GET 与 POST？** GET 通常用于读取，POST 常用于创建或提交处理；幂等性和缓存不能只按方法名猜，要看接口语义和实现。

**Q：线上模型延迟升高怎么办？** 拆请求耗时、特征获取、召回、排序、重排和下游调用；检查 p95/p99、流量、缓存命中与资源饱和，并准备降级策略。
