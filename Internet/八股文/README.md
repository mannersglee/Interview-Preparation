## 每题的回答模板

1. **一句话定义**：先说是什么、解决什么问题。
2. **关键公式或流程**：只给能影响结论的步骤。
3. **前提与陷阱**：数据粒度、随机化、偏差、泄漏、业务护栏。
4. **一个场景**：把知识点落到增长、内容、搜索、直播或推荐上。

## 复习方式

第一遍不看答案口述 60 秒；答不出再看笔记。第二遍写 SQL、公式或伪代码；第三遍找反例。错题记“为什么错”和“正确判断条件”，不要只背结论。配合 [PRE 的 14 天计划](../PRE/02-14天学习计划.md) 和[岗位专项题](../PRE/03-岗位专项与面试题.md)使用。
