# 业务指标与分析

## 通用指标口径

**Q：DAU、WAU、MAU 是什么？** 指每日、每周、每月在定义的活跃事件下去重的用户数。必须补充：统计时区、自然日还是滚动窗口、游客与登录用户如何合并、异常账号是否排除。

**Q：留存率怎么算？** 某 cohort 在指定后续窗口仍活跃的人数 / 该 cohort 初始人数。次日留存按注册次日活跃；7 日留存需说清“第 7 天活跃”还是“第 1–7 天任一天活跃”，二者不同。

**Q：转化率、CTR、CVR？** CTR 常为点击量/曝光量，CVR 的分母可能是点击、访问或下单前用户，必须先问清业务口径。用户级、次数级指标不能混用。

**Q：平均值为什么骗人？** 重度用户或头部主播可能主导均值。补充中位数、分位数、分群、总量、样本量；同时看构成变化和辛普森悖论。

## 异动分析框架

1. **先验数**：埋点改动、延迟、重复、去重、时区、看板口径、数据回填。
2. **再定位**：新老用户、渠道、版本、设备、地区、时段、内容/商品类型；找贡献最大的分群。
3. **看链路**：总量 = 流量 × 转化率 × 频次 × 客单价等，拆到可行动环节。
4. **找外因**：节假日、活动、竞品、供给、系统故障、政策变化。
5. **验证而非猜测**：对照组、历史同期、实验或准实验；附上不确定性。

**Q：DAU 下跌 8% 怎么查？** 先确认日志健康，再看新增与老用户留存哪部分贡献大；按渠道、版本和关键行为拆分；若集中在某版本，检查发布、性能和曝光；形成可验证假设与恢复动作。

**Q：CTR 上升但 GMV 下降？** 可能是点击诱导、低价商品占比上升、CVR/客单价下降、高价值 query 流量下跌、位置偏差或口径变化。按 query 意图、新老用户、商品类目及价格带拆解，并看长期护栏。

## 场景指标树

| 场景 | 主链路 | 护栏或易忽视指标 |
| --- | --- | --- |
| 用户增长 | 获客 → 激活 → 留存 → 频次 → 价值 | 获客成本、低质量注册、长期留存 |
| UGC 内容 | 作者活跃/投稿 → 审核 → 曝光 → 有效消费 → 互动 → 作者留存 | 低质内容、创作者分布、公平性、举报 |
| 电商搜索 | query → 有结果 → 曝光 → 点击 → 加购 → 下单 → 复购 | 相关性、无结果率、退款、用户满意度 |
| 直播 | 主播开播与供给 → 匹配分发 → 观看/互动 → 付费与留存 | 主播生态、头部集中、投诉、时长质量 |
| Agent/AI 搜索 | 任务发起 → 答案/动作完成 → 用户确认 → 复访 | 错误率、人工接管、时延、成本、安全 |
| 用户画像 | 数据采集 → 标签生成 → 覆盖 → 策略应用 → 效果 | 准确率、时效、漂移、偏差、误判成本 |

## 画像标签高频问答

**Q：标签准确率如何评估？** 先明确“真值”如何得到；抽样人工核验或用后续行为验证，报告覆盖率、精确率/召回率、不同人群误差和更新延迟。仅看总体准确率可能掩盖小群体问题。

**Q：为什么标签不宜直接用未来行为定义特征？** 会产生时间泄漏，离线表现虚高，线上无法获得。必须固定观察窗和预测窗。

## Agent 指标高频问答

**Q：使用量上升是否说明 Agent 有价值？** 不一定。可能只是入口曝光增加或重复尝试变多。应看质量合格的任务完成率、节省时间、人工接管、满意度及长期留存，并明确任务级而非消息级口径。
