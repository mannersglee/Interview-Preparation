# 14 天学习计划

每次学习建议分成 90 分钟动手、60 分钟概念、30 分钟口述、30 分钟复盘。若时间不足，只做“最低交付”。环境沿用 `/opt/anaconda3/envs/myenv/bin/python`；SQL 可用该环境的 `sqlite3` 标准库练习，不依赖公司内部数据。

| 天数 | 主题与任务 | 当日最低交付 | 自测通过标准 |
| --- | --- | --- | --- |
| D1 | 建一套模拟互联网数据表：`users(user_id,signup_date,channel)`、`events(user_id,event_time,event_type,content_id)`、`experiments(user_id,group_id,assigned_at)`、`orders(user_id,order_time,amount)`；说明主键、时间区、去重规则 | 数据字典 + 4 张表各 10 行样例 | 能解释注册、曝光、活跃、支付事件如何关联，避免事件重复导致人数膨胀 |
| D2 | SQL 基础：JOIN、GROUP BY、条件聚合、NULL、日期截断；计算 DAU、新增和渠道占比 | 4 条 SQL + 手工核对 1 天结果 | 说清 `COUNT(*)`、`COUNT(DISTINCT user_id)` 差异，JOIN 后不重复计数 |
| D3 | SQL 进阶：窗口函数、去重、留存 cohort、7 日活跃、漏斗 | 次日/7 日留存与曝光→点击→转化漏斗查询 | 明确分母、观察窗、用户粒度和迟到日志；结果无未来信息泄漏 |
| D4 | 增长和内容指标：为百度增长、抖音 UGC 画指标树；模拟 DAU 下跌 8% 的排查 | 1 页指标树 + 异常排查清单 | 能按“数据质量→分群→环节→外因”排序，不直接把相关性当原因 |
| D5 | 业务分析：拆新增、活跃、留存，按渠道/端/地区/新老用户分层；做一页图表和建议 | 1 页分析 memo | 每个结论对应一个图或查询，并标明样本量与风险 |
| D6 | A/B 设计：随机化单元、指标、护栏、MDE/功效、实验周期、停止规则 | 一份实验方案 | 讲清主指标为何选它、可能的干扰和曝光口径 |
| D7 | A/B 分析：SRM、AA、ITT、置信区间、CUPED、分群与多重检验 | 一份模拟实验报告 | 先检查分流与数据质量，再谈显著性；不把“不显著”说成“无效” |
| D8 | 因果方法：PSM/加权、DiD、DML、Uplift 的目标与假设；连接本人动态因果论文 | 1 张方法选择表 + 3 分钟论文陈述 | 可解释 PSM 不解决未观测混杂、DiD 需平行趋势、Uplift 估计个体增量有不确定性 |
| D9 | 搜索与电商：搜索词→曝光→点击→下单指标树；分析 CTR 升高而 GMV 下降 | 搜索指标树 + 1 页诊断 memo | 能区分排序点击率、转化率、客单价、供给变化及位置偏差 |
| D10 | Agent 与 AI 搜索：任务成功率、覆盖、留存、质量、耗时；埋点和 bad case 分类 | Agent 指标字典 + 5 类失败样例 | 能区分使用量增长与实际任务价值，提出人工质检和护栏 |
| D11 | 美团画像与直播生态：标签覆盖率、准确率、稳定性；主播供给、看播、互动、付费、留存 | 两张指标树 + 标签质检方案 | 说清标签来源、更新时间、样本偏差，以及直播双边生态的联动 |
| D12 | 推荐算法：协同过滤/内容召回、排序基线、负采样、时间切分；计算 Recall@K、NDCG@K、AUC | 可运行 notebook 或脚本 + 指标表 | 无训练/验证泄漏；能解释离线指标提升不保证在线收益 |
| D13 | 模拟面试：SQL 45 分钟、业务 case 30 分钟、实验 case 30 分钟、简历项目 30 分钟 | 错题表 + 2 段录音或文字复盘 | 每题能给出假设、计算或验证、边界；真实经历与模拟练习分明 |
| D14 | 岗位定向：按首个面试岗位读专项卡，重写 1 分钟自我介绍及 3 分钟项目讲述 | 一页最终面试提纲 | 不看稿能讲清一段实习、一项因果研究、一项业务分析练习 |

## 每周检查点

- **D3 后：**SQL 留存与漏斗可以从空白写出；不会时优先修 SQL，不急着看高级因果模型。
- **D7 后：**能拿模拟实验数据从 SRM 到决策结论走通一遍。
- **D11 后：**能根据面试岗位在增长、内容、搜索、直播、Agent、画像之间切换指标口径。
- **D14 后：**至少有一份可复现分析报告和一次完整模拟面试记录。

## 面试通知插队规则

接到面试通知当天暂停非目标岗位内容：先复习个人简历项目（60 分钟），再读目标岗位专项（30 分钟），最后做该岗位最常见的 SQL/业务/算法题（60 分钟）。若同时收到多个面试，按**最早面试时间**排序，不按公司名气排序。
