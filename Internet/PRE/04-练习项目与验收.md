# 可复现练习项目与验收

目的：把 8 个岗位的高频能力练成可展示的证据。所有练习用**公开或模拟数据**，在报告首页写清来源；不要写成公司真实业务结果。可以放在本地 `PRE/practice/`，这份计划本身不预设已经完成。

## 项目 A：用户增长与内容实验分析（优先完成）

**场景：**假设一个内容产品推出创作者激励，观察投稿、分发、消费和留存。数据表为用户、内容、曝光、点击/观看、互动、实验分组与每日活跃。

**步骤与成果：**

1. **数据字典**：每张表记录粒度、主键、时间区、埋点含义、去重规则和缺失值处理。
2. **SQL 查询**：计算 DAU、新增、次日/7 日留存；按渠道和新老用户拆分；完成内容供给→曝光→互动漏斗。
3. **异常分析**：主动注入一处重复日志或漏数，写出发现、定位、修复前后指标变化。
4. **实验设计**：写主指标、护栏、随机化单元、最小有价值效果、周期、停止规则和干扰风险。
5. **实验分析**：先做 SRM 和数据质量检查，再算效果、置信区间与分群；如做 CUPED，协变量必须来自干预前。
6. **业务 memo**：一页回答“是否推广激励策略”；若模拟数据结论不明确，直接写证据不足和下一步实验。

**验收：**新环境中 10 分钟内能从原始数据复现图表；查询中的人数均用明确去重口径；报告有数据来源、样本量、区间、护栏和局限。这个项目主要服务百度增长、百度 AI 数据分析、抖音 UGC、TikTok 直播。

## 项目 B：搜索策略与因果评估（第 2 优先）

**场景：**假设电商搜索更改排序策略，历史日志中并非随机分配。建立 query、曝光、位置、点击、订单和策略版本数据。

**步骤与成果：**

1. 定义 CTR、CVR、GMV、搜索成功率、无结果率和长期护栏，说明它们的分母及观察窗。
2. 用 SQL 和 Python 拆 query 意图、商品类目、新老用户、位置；解释混合口径可能造成的辛普森悖论。
3. 先展示朴素比较的偏差，再做 PSM 或逆概率加权，报告重叠性、匹配后平衡和敏感性；如练 DML，使用交叉拟合并说明不能自动消除未观测混杂。
4. 写一页“若允许线上 A/B，如何重新设计”的方案，区分离线证据和上线证据。

**验收：**能说清为什么选择该方法、识别假设是什么、违反时结论往哪个方向偏；提供可复现代码与 1 页摘要。主要服务抖音电商搜索、TikTok Shop AI 搜索。

## 项目 C：推荐系统基线（算法岗位必做）

**场景：**用公开的用户-内容交互数据做图文推荐的简化问题。不要自称复现百度生产推荐系统。

**步骤与成果：**

1. 按时间切训练/验证/测试，排除测试时间之后的特征；定义正负反馈和未曝光样本的处理方式。
2. 先做热门内容 baseline，再做 item-based 协同过滤或内容特征召回；有余力再加简单排序模型。
3. 输出 Recall@20、NDCG@20、覆盖率与新用户/长尾内容分组结果；解释这些指标与在线留存、多样性之间的差异。
4. 分析至少 3 个失败案例：冷启动、热门偏置、行为稀疏或时间漂移；提出线上实验主指标和护栏。

**验收：**基线有明确对照，划分无泄漏，代码可复现，能 3 分钟讲清模型、指标、误差和下一步。主要服务百度推荐算法。

## 项目 D：画像标签与 Agent 指标（补充）

**用户画像：**设计“潜在高价值用户”标签，定义业务用途、训练观察窗、预测窗、覆盖率、抽样核验准确率、更新时间与漂移；比较不同用户群的误判成本。服务美团商业分析。

**Agent：**定义任务成功率、人工接管率、时延、满意度与 7 日留存；列日志事件、字段和 bad case 分类，设计新版本实验。服务百度 AI 数据分析。

**验收：**各有一页指标字典和一页业务决策说明，任何指标都能回答“谁在分母中、什么时候记一次、异常如何验数”。

## 交付物清单

- `data_dictionary.md`：数据来源和口径。
- `queries.sql`：可运行的 SQL，标注数据库方言。
- `analysis.py` 或 notebook：环境、随机种子、运行步骤。
- `experiment_plan.md` 和 `report.md`：方案、质量检查、结果、局限。
- `interview_notes.md`：1 分钟项目简介、3 分钟展开、5 个可能追问。

## 投递与面试中的表达边界

真实经历中的量化研究、论文与竞赛按事实陈述。新项目完成后可写“个人练习项目（公开/模拟数据）”，明确数据性质。SQL、PyTorch、推荐系统或 A/B 实操只有在能独立运行、解释和复现时才加入技能栏。
