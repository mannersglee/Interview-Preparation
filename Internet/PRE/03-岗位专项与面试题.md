# 8 个岗位的专项准备

以下是针对用户提供的岗位描述做的面试准备，不代表公司实际面试题。每个岗位先讲共通能力，再补其业务场景。真实项目可引用量化研究实习、动态因果效应论文与在线医疗分析；练习项目应明确说“模拟数据”。

## 1. 百度 MEG 数据分析 J106400

**准备重点：**DAU、新增、次日/7 日留存、用户分层、渠道质量、异动分析。能从“业务问题→指标口径→SQL→原因假设→验证→建议”完整讲一遍。

**必做练习：**用 D1–D3 的数据做按注册渠道分组的 cohort 留存表；模拟“DAU 连续 3 天下跌”，先检查日志/去重，再拆新老用户、地区、版本、渠道和关键行为漏斗。

**自测题：**① DAU 上升但留存下降可能意味着什么？② 新增多、活跃不变时如何定位？③ 如何定义“用户流失”，为什么窗口不同结论不同？④ SQL 多表 JOIN 后留存率异常偏高怎样排查？

**简历讲述重点：**高频数据清洗和一致性验证可以转化为“保证指标可信”的能力；不要把金融市场分析说成互联网增长经验。

## 2. 百度 AI 数据分析 J106779

**准备重点：**Agent 使用覆盖率、留存、任务完成率、人工接管率、满意度、处理时长，以及可靠性护栏。埋点需记录任务 ID、用户 ID、意图、工具调用、成功判定、失败原因、耗时和版本。

**必做练习：**为企业内部 Agent 设计一张指标字典，设计“新版本是否真的提升工作效率”的实验：主指标可选完成任务耗时或质量合格的任务完成率，护栏关注失败、投诉、成本。写明可能的选择偏差与用户学习效应。

**自测题：**① 日活提高而任务成功率下降，是否上线？② Agent 的“任务完成”如何定义并质检？③ 新功能只有高活跃用户使用，如何评估真实效果？④ 实验样本量不足时怎样报告？

**简历讲述重点：**潜在结果与动态因果效应研究；统计假设和结果可信度；不要声称已有企业 Agent 实习经验。

## 3. 百度 MEG 推荐算法 J106848

**准备重点：**召回、粗排/精排、重排；协同过滤与内容特征；用户/物品冷启动；负采样；时间切分；Recall@K、NDCG@K、AUC 与线上留存/满意度的关系。图文推荐还需考虑多样性和公平性。

**必做练习：**用公开数据或明确标注的模拟交互数据做 popularity baseline 与一个协同过滤/内容召回 baseline；输出 Recall@20、NDCG@20，并解释线上实验应该监控哪些主指标和护栏。

**自测题：**① 为什么随机划分交互数据会高估离线效果？② 新用户无历史行为如何推荐？③ CTR 提升但留存下降为何可能发生？④ 如何检查训练特征中是否混入曝光后的信息？

**差距与策略：**现有简历未核实推荐系统实战和 PyTorch。先能讲清基线、评估和失败案例，再逐步扩展深度模型；面试中如实说明练习性质。

## 4. 美团平台商业分析

**准备重点：**用户画像标签的覆盖率、准确率、时效性、稳定性、可解释性；不同业务场景对标签的需求。跨算法、数仓、业务团队协作时，先统一标签定义、数据血缘和验收口径。

**必做练习：**设计“高价值用户”标签：列出候选特征、观察窗、预测窗、漏数处理、样本偏差、标签更新频率和人工抽检方案；写一页标签质量报告。

**自测题：**① 标签覆盖率提高却让策略效果下降，如何排查？② 同一用户多端行为如何归并？③ 标签按订单金额定义会怎样偏向老用户？④ 如何向业务方解释标签误判成本？

**简历讲述重点：**数据标准化、数据库一致性检查、基于回归识别相关因素的项目经验。

## 5. 抖音 UGC 数据分析

**准备重点：**供给→分发→消费→互动→创作者留存的指标链。内容生态不能只看播放量，还要看优质创作、互动质量、作者活跃和用户体验。实验要区分内容、创作者和用户三个随机化层级。

**必做练习：**画 UGC 内容漏斗，模拟“投稿量增加但互动率下降”；拆新作者/老作者、内容类型、推荐流量、曝光位置和审核变化。设计鼓励新作者发布的 A/B 实验，写明网络效应和溢出风险。

**自测题：**① 投稿量上升但有效作者留存下降说明什么？② 指标分母选曝光数还是观看用户数？③ 内容策略实验中用户可能同时看到两组内容，如何处理干扰？④ 看板突然断崖式下降，先查什么？

**岗位门槛提醒：**岗位信息列有 SQL 熟练、每周至少 4 天和连续至少 3 个月；投递材料和面试回答须与真实情况一致。

## 6. 抖音电商搜索数据科学

**准备重点：**query→结果曝光→点击→加购→下单→复购；搜索意图、结果相关性、商品供给、价格、营销和位置偏差。策略评估不仅看 GMV，还要看用户体验、商家公平与长期留存。

**必做练习：**分析“搜索 CTR 上升但 GMV 下降”的可能机制，设计最少 5 个排查分组；用模拟数据比较原始转化率和按 query 类别分层后的转化率。对非随机历史策略尝试 PSM/加权，检查重叠性和平衡，不把结果当作随机实验。

**自测题：**① 搜索 AB 实验的随机化单元选用户还是 query？② PSM 不能解决什么偏差？③ Uplift 与普通转化预测目标有何不同？④ DML 的交叉拟合用于解决什么问题？⑤ 新排序提升点击但降低复购，怎样决定上线？

**简历讲述重点：**动态因果研究可说明方法基础；量化研究中样本内外一致性评估可说明验证意识。电商指标需单独补习。

## 7. TikTok 直播数据科学

**准备重点：**观看端（曝光、进入、观看时长、互动、付费、留存）与主播端（开播、有效开播、供给时长、主播留存）的双边指标。注意推荐分发、主播激励和活动造成的相互干扰。

**必做练习：**模拟“观看时长上升但主播留存下降”，列出分群、供需匹配和竞争分配角度的假设；设计直播推荐策略实验，明确主指标、护栏、随机化单元和溢出风险。

**自测题：**① 平均观看时长与总观看时长各有什么局限？② 主播大促活动期间能否直接做前后对比？③ 对高活跃主播的策略效果能否推广到新主播？

## 8. TikTok Shop AI 搜索数据科学

**准备重点：**AA 与 AB 的不同用途；埋点、宽表验数、指标字典、实验报告 SOP。AI 搜索还需关注答案正确性、商品相关性、无结果率、时延及用户信任。

**必做练习：**为 AI 搜索上线建立“日志事件→宽表字段→指标 SQL→AA 检查→AB 报告”检查清单；设计 20 条 bad case 的错误分类和人工复核流程。

**自测题：**① AA 实验显著差异意味着什么？② 搜索答案质量如何与下单指标结合？③ 埋点改版前后指标不可比时怎样处理？④ SRM 出现后为什么不能继续直接解读实验效果？

## 通用口述框架

- **业务题：**目标和主指标 → 数据口径 → 假设拆解 → 证据与反证 → 建议、护栏及下一步。
- **实验题：**决策问题 → 随机化 → 主指标/护栏 → 样本量与时长 → SRM/数据质量 → 效果与区间 → 风险和上线建议。
- **项目题：**本人负责什么 → 为什么选方法 → 数据与验证 → 结果 → 局限和迁移边界。论文和金融实习都按这一框架讲，不夸大为线上互联网实践。
