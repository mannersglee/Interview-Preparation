## Demo 1：补贴策略 A/B 实验评估

- **问题**：新用户补贴是否带来有经济价值的增量完单？
- **设计**：以用户为随机化单元，预先定义主指标（人均完单）、成本指标（每增量完单补贴成本）与护栏指标（取消率、等待时长）；估算 MDE、样本量和实验周期。
- **分析**：模拟分流与订单数据；做 SRM、基线平衡和缺失检查；估计 ITT、置信区间；用实验前行为做 CUPED 降方差；按预设新老用户群体查看异质性。
- **产出**：实验方案、诊断表、效果与成本图、一页上线/继续试验/停止建议。
- **关键讨论**：补贴外溢到司机供给时，用户级随机化的结论可能受干扰。

## Demo 2：城市策略灰度上线的双重差分评估

- **问题**：某城市上线派单规则后，平均接驾时长是否下降？
- **设计**：模拟处理城市与可比对照城市的周度数据；明确上线时间、同期活动、天气和节假日；在分析前定义比较窗口。
- **分析**：画干预前趋势；估计 DiD 效应；做事件研究图、安慰剂时间检验和更换对照城市的敏感性分析；按城市聚类或说明城市数不足时的不确定性。
- **产出**：趋势图、估计表、识别假设检查与“能否归因”的结论。
- **关键讨论**：若上线恰逢独有的城市政策或供需冲击，平行趋势可能失效。

## Demo 3：双边市场实验的干扰与分流方案比较

- **问题**：提高部分订单的司机激励，会不会通过共享司机供给影响对照订单？
- **设计**：模拟用户、司机、区域和时间段构成的简化网络；比较订单级随机、区域级随机与时间切换设计。
- **分析**：在不同溢出强度下模拟估计偏差与方差；展示为什么订单级分析可能高估或低估总体效果；说明区域间跨界和时间滞后问题。
- **产出**：分流方案对比图、推荐设计及其适用条件。
- **关键讨论**：更大的随机化单元减少污染，但有效样本量也可能下降。

## Demo 4：实验质量诊断与报告助手

- **问题**：多业务团队重复检查分流、埋点和指标口径，初版报告耗时且易漏项。
- **设计**：输入模拟实验登记信息、分流日志、曝光日志、指标字典和聚合结果；定义必须通过的规则和人工复核点。
- **分析/流程**：自动计算 SRM、缺失率、样本流失、基线平衡、主指标效应与护栏变化；生成带数据来源和查询版本的报告草稿；让 Agent 仅根据结构化结果解释，无法验证的结论标记为待复核。
- **产出**：可审计的检查清单、异常示例、报告模板和人工审核记录。
- **关键讨论**：自动化提高效率，因果识别假设与最终上线决策仍需负责人审查。

## Demo 5：非随机触达策略的匹配与敏感性分析

- **问题**：运营定向触达高活跃用户后，留存上升是否由触达造成？
- **设计**：模拟包含历史活跃度、城市、渠道和留存的数据，刻意制造选择偏差；明确只使用触达前变量。
- **分析**：比较原始差异、倾向得分加权/匹配后的结果；展示特征平衡、倾向得分重叠性；用未观测混杂的敏感性情景说明结论边界。
- **产出**：方法对比、平衡图、效果区间与是否值得开展随机验证的建议。
- **关键讨论**：可观测变量平衡不代表未观测混杂已消失。
